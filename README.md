# Expense-shell

```sh
git clone https://github.com/wavedevops/expense-shell.git
```

1. to connect data base

```sh
mysql -h <private-ip> -uroot -pExpenseApp@1
```
2. to debug

```md
-- Show all databases
SHOW DATABASES;

-- Select the 'transactions' database
USE transactions;

-- Show all tables in the selected database
SHOW TABLES;

-- Display all records from the 'transactions' table
SELECT * FROM transactions;
```
